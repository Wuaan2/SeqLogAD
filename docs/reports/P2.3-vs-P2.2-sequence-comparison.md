## 3. Reading

- P2.3 matches or exceeds P2.2 on every reported capability metric in both folds, at 0.46% of the
  parameters, about 15% of the peak VRAM and about one sixth of the time per step.
- The evidence is weak. There are only 10 positive HDFS blocks and 16 positive BGL lines, so a single
  true positive moves F1 by roughly 0.05–0.10. The metrics are the maximum over checkpoints on the same
  512 windows used for selection, so both are optimistic. Per-window scores were not saved, so no
  confidence interval can be computed from these runs.
- Both runs stopped early, far below their step budgets, so neither budget limited capability.
- Conclusion for this development wave: **the lightweight candidate is viable; superiority is not
  claimed.** A paired comparison on validation windows not used for checkpoint selection, with unit-level
  bootstrap intervals, belongs to P2.6 and needs the C2 label-scope decision.

Not claimed: target performance, multi-seed stability, a sequence winner.
