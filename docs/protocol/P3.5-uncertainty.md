## The rule

**An expert abstains only when its evidence is insufficient, never because its input is unusual.** Unseen events,
distance to the buffer prototypes, token-NLL dispersion and disagreement between experts all rise with the anomaly
signal itself. Turning any of them into abstention would hide anomalies, so they are reported and never used to
abstain.

| Level | UNKNOWN_REVIEW when | Otherwise |
|---|---|---|
| Expert × unit | the envelope is ABSTAIN, or LOW_COVERAGE (cropped input), or the expert has no CAL-CS-001 scale | SCORED |
| Window | fewer than 2 experts are SCORED (QUORUM) | ASSESSABLE |

An UNKNOWN_REVIEW expert or window gets no normal or anomaly label. That is the P3.5 definition of done: unknown is a
first-class outcome.

## Uncertainty values, reported and not used to abstain

- `input_uncertainty = 1 − coverage`, from the EVID-CS-001 envelope, with the same formula for every expert.
- `native_uncertainty`: the expert's own uncertainty field put on one scale. It is the share of the expert's
  burn-in buffer values that are at or below the window's value (a target-normal ECDF in [0, 1]).
  - The buffer values come from the P3.2 buffer pass. A file is accepted only if its SHA-256 equals the evidence hash
    in the frozen prototypes component.
  - GTAT emits no native uncertainty (`UNCERTAINTY_NOT_ESTIMATED_IN_PHASE2`). Its value is null and its status is
    NOT_AVAILABLE; it is never filled in.
- Window uncertainty is the mean normalised native uncertainty over the SCORED experts that have one.
- The DRIFT-CS-001 block state is reported next to the window state and never changes it.

## Reports

- **Now (label-free):** abstention rate per expert, reason and fold, and the window abstention rate on the buffer.
  These are the example outputs.
- **In the locked final evaluation only (labels):**
  - risk–coverage: the average precision of the fused score on the ASSESSABLE windows with the lowest uncertainty,
    at coverage 1.0, 0.95, 0.9 and 0.8;
  - UNKNOWN_REVIEW windows reported three ways (excluded, counted as alerts, counted as normal), with none of the
    three chosen as the result.

[`configs/protocols/p3.5-receipt-v1.yaml`](../../configs/protocols/p3.5-receipt-v1.yaml). No buffer window fails the
