`src/seqlogad/memory/build.py`, driver `scripts/build_target_memory.py`. Authorized by the researcher on

## What the memory is

For each target fold under EXC-007 (HDFS, BGL), a label-free picture of "normal" for the target system,
learned only from its approved burn-in buffer (ADAPT-INPUT-001, signed at G0):

| Component | Content | Records used |
|---|---|---|
| `statistics/unigrams` | count of every normalized event (`norm_h`) with one example text | all buffer records |
| `statistics/transitions` | first-order event transition counts; history resets at each group, GLOBAL if none (P2.2 rule) | all buffer records |
| `statistics/windows`, `events` | TARGET_BURN_IN windows in the P2.2 format (8 predecessors), selected by the P2.2 hash rule, 32,768 per fold | buffer only |
| `statistics/graphs`, `nodes`, `node_attributes` | the GTAT graph view of those windows and the distribution of component, severity and location | buffer only |
| `prototypes/` | expert embeddings of the windows (all four experts), computed on Colab | buffer only; pending |

## Guarantees

1. **Approved buffer only.** The folds and buffers are rebuilt from the Phase-1 streams with the label-free
   P1.5/P1.6 code. The rebuilt buffer must equal the G0 buffer in records, rank-membership SHA-256,
   distinct-message count, first and last timestamps, raw-file SHA-256 and normalizer hash, and must be
   `ACCEPTED`, or the build stops. Every record outside TARGET_BURN_IN is filtered out before any text is
   read; no label file is opened; no model score is used to select anything.
2. **Content checked twice.** The raw chronology must equal the frozen stream (rank, timestamp, group), and
   every normalized text must hash to the stream's `norm_h`. The P2.4 graph builder re-checks both.
3. **Keyed.** Every component carries `memory_key = ADAPT-MEM-001/<target>/<buffer membership SHA-256>`.
4. **Frozen.** A component is written once into its own folder, every file is hashed into
   `component.json` and made read-only; `load_component` re-hashes everything on each read. The fold
   memory is frozen by a final `memory.json` binding all component hashes, written after the prototypes.
   Evaluation code only reads it; a change is a new memory version.

`stream-index.json` records `scan_seconds`, so its own SHA-256 is not reproducible and is not pinned; the
values above are.
